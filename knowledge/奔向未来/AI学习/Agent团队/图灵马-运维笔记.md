### ⚠️ 微信 Token 冲突

**现象**: `Weixin bot token already in use (PID XXXX)`

**原因**: turingma 和 obama 两个 profile 共用了同一个微信 bot token，不能同时运行。

**解决**:
1. 找到占用 token 的进程 PID
2. 终止冲突进程：`taskkill /PID XXXX /F`
3. 重启网关


### ⚠️ Provider 认证失败

**现象**: `401 - Missing Authentication header`

**原因**: 切到某个 provider 后，对应 API Key 未在 `.env` 中配置。

**排查**:
```bash
env | grep -i api_key
```

**解决**: 要么添加缺失的 API Key，要么切回已有密钥的提供商。

### ⚠️ Cron Job Provider 漂移

**现象**: `global inference config drifted since this job was created`

**原因**: 创建 cron job 时使用的 provider/model 和当前全局配置不一致，系统为防止意外扣费自动跳过。

**解决**: 显式锁定 cron job 的提供商和模型：
```bash
cronjob action=update job_id=xxx model='{"model":"deepseek-ai/DeepSeek-V3","provider":"siliconflow"}'
```

## Cron Job 管理

```bash
# 列出所有任务
hermes cron list

# 创建任务
cronjob action=create name="名称" schedule="10 08 * * *" prompt="内容" deliver=weixin

# 更新任务
cronjob action=update job_id=xxx model=...

# 暂停/恢复
cronjob action=pause job_id=xxx
cronjob action=resume job_id=xxx

# 删除
cronjob action=remove job_id=xxx
```
