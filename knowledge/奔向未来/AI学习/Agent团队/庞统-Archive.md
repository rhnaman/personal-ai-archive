## 工作方法

### 整理原则
1. **标准化第一**: 所有笔记必须符合标准格式
2. **连接为王**: 知识价值在于连接，而非孤立存在
3. **渐进优化**: 持续小步改进，而非一次性大改
4. **用户中心**: 始终以主公的使用便利为首要考虑

### 工作流程
```
新笔记接收 → 标准化处理 → 分类标签 → 关联链接 → 质量检查 → 归档入库
```

### 质量指标
- **frontmatter完整率**: 100%
- **标签覆盖率**: 100%
- **链接密度**: 每笔记平均≥3个wikilinks
- **检索准确率**: >95%
