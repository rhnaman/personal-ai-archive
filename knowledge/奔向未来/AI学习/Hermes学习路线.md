# Hermes 学习路线

> Nous Research 开源的"会自我进化、记得住用户"的下一代 AI Agent 框架。
> 底层模型 Hermes 3（基于 Meta Llama 3.1），GitHub 11万+ stars，口号 "The Agent That Grows With You"。

## 学习概览

| 维度 | 内容 |
|------|------|
| **学习主题** | Hermes Agent 框架及其底层模型 Hermes 3 |
| **学习目的** | 理解自我进化型 AI Agent 架构，探索个人 AI 助手进化方向 |
| **预期收获** | 掌握 Agent 记忆机制、自我进化原理、可落地的集成方案 |
| **预计周期** | 4-6 周（2026-05-09 → 2026-06-20） |
| **难度等级** | ⭐⭐⭐⭐（高等） |

## 知识体系

```
Hermes Agent 知识图谱
├── 1. 基础认知
│   ├── Hermes 3 模型架构（基于 Llama 3.1）
│   ├── Agent 框架设计哲学
│   └── "自我进化"的核心定义
├── 2. 核心机制
│   ├── 长期记忆系统（Long-term Memory）
│   ├── 用户建模与个性化（User Modeling）
│   ├── 工具调用与函数编排（Tool Use）
│   └── 反思与自我改进循环（Self-Reflection Loop）
├── 3. 技术架构
│   ├── 推理引擎（Inference Engine）
│   ├── 记忆存储层（Memory Storage Layer）
│   ├── 知识检索（RAG/Vector Search）
│   └── 多模态集成（Multimodal）
└── 4. 实践应用
    ├── 本地部署方案
    ├── 与 Obsidian/笔记系统集成
    └── Agent 团队协作扩展
```

## 学习阶段

**目标**：理解 Hermes Agent 是什么、能做什么、独特价值在哪

**目标**：掌握记忆系统、自我进化、工具调用三大核心机制

- [ ] 学习函数调用（Function Calling）与工具编排
