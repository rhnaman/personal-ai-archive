# 毛泽东核心著作分析

## 哲学著作：思想方法论

### 《实践论》（1937）

**核心论点**：认识来源于实践，最终要回到实践中去检验。

三层结构：
1. **感性认识阶段**：看到事物的现象和外部联系
2. **理性认识阶段**：上升到对事物本质和规律的认识
3. **再回到实践中去检验**：理论是否正确要由实践来判断

形成故事的来源：1930年代初在中央苏区被排斥的经历——他批评教条主义者"马克思主义是灵丹妙药"的思维方式，亲身实践成了他最大的说服力。

**认知意义**：这不是纯哲学讨论，这是对党内教条主义的批评。"知行统一"的观念贯穿了他后来所有的决策。

### 《矛盾论》（1937）

**核心论点**：对立统一法则是一切事物发展的根本规律。

关键概念树：
- 矛盾的普遍性 → 矛盾无处不在
- 矛盾的特殊性 → 不同矛盾不同解法
- 主要矛盾和次要矛盾 → 抓主要矛盾
- 矛盾的主要方面和次要方面 → 矛盾转化
- 矛盾诸方面的同一性和斗争性
- 对抗在矛盾中的地位

**认知意义**：这是他分析一切问题的"操作系统"。后来分析国际形势、党内矛盾、经济问题，全是这个框架。

## 军事著作：战略方法论

### 《中国革命战争的战略问题》（1936）

**核心框架**：
1. 战略规律是客观存在的，要学会认识它
2. 中国革命战争有四个特点：政治经济发展不平衡、敌人强大、红军弱小、共产党领导和土地革命
3. 战略防御是关键——"积极防御"不是消极挨打，而是为了反攻

**关键命题**："战略退却是为了保存军力，准备反攻。战略退却的目的是为了保存军力。"

**认知意义**：以退为进、以弱胜强的系统方法论。

### 《论持久战》（1938）

**核心论点**：中日战争是持久战，经过三个阶段——战略防御、战略相持、战略反攻。

预判的依据：
1. 敌强我弱 → 不能速胜
2. 敌退步我进步 → 不会亡国
3. 敌小我大 → 我们有空间换时间
4. 敌寡助我多助 → 国际形势有利于我

**认知意义**：在"亡国论"和"速胜论"的对立中，不走中间路线，而是建立独立的分析框架。这是他最经典的"第三种选择"案例。

## 政治著作：路线和方法

### 《湖南农民运动考察报告》（1927）

**方法论意义**：32天、5个县、实地考察。他后来多次提到这是"最值得回忆的一件事"。

核心方法论："没有调查就没有发言权"——后来在《反对本本主义》（1930）中系统化。

### 《反对本本主义》（1930）

**五个命题**：
1. 没有调查就没有发言权
2. 调查就是解决问题
3. 反对本本主义（教条主义）
4. 中国革命斗争的胜利要靠中国同志了解中国情况
5. 社会经济调查是为了得到正确的阶级估量

**认知意义**：这篇是他独立自主思想的早期表达。几十年后他依然强调"独立自主、自力更生"。

## 著作中反复出现的思维习惯

| 思维习惯 | 出现频率 | 典型案例 |
|----------|----------|----------|
| **抓主要矛盾** | 贯穿所有著作 | 分析任何问题先找"主要矛盾和矛盾的主要方面" |
| **调查研究先行** | 持续强调 | "一切从实际出发" |
| **从实践中来** | 反复论述 | 《实践论》全篇 |
| **矛盾转化思维** | 核心方法论 | 坏事变好事、劣势变优势 |
| **分清敌我友** | 战略分析第一步 | 《中国社会各阶级的分析》开篇 |
| **底线思维** | 军事和政治策略 | 战略退却保存实力 |
