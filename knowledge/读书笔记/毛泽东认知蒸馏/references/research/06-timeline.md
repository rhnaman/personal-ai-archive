# 毛泽东生平时间线

## 早期（1893-1920）：从农家子到马克思主义者

| 时间 | 事件 | 认知意义 |
|------|------|----------|
| 1893.12.26 | 生于湖南湘潭韶山冲农民家庭 | 农村出身深刻影响其后对农民问题的重视 |
| 1902-1909 | 读私塾，读《水浒》《三国》等 | 反抗精神和军事叙事的最早来源 |
| 1911 | 到长沙求学，响应辛亥革命参军 | 第一次走出乡村接触政治变革 |
| 1913-1918 | 就读湖南第一师范 | 形成"野蛮其体魄，文明其精神"的理念；师从杨昌济；结识蔡和森等 |
| 1917 | 写《心之力》 | 早期唯心主义哲学训练，强调意志力量 |
| 1918 | 第一次到北京，在北大图书馆工作 | 接触李大钊、陈独秀；读到马克思主义书籍 |
| 1919 | 五四运动；创办《湘江评论》 | 开始用革命视角分析中国问题 |
| 1920 | 读《共产党宣言》→确立马克思主义信仰 | 核心转折：从民主主义转向马克思主义 |

## 革命时期（1921-1935）：从建党到遵义会议

| 时间 | 事件 | 认知意义 |
|------|------|----------|
| 1921 | 参加中共一大 | 建党元老之一 |
| 1925 | 写《中国社会各阶级的分析》 | 确立阶级分析方法 |
| 1927.3 | 写《湖南农民运动考察报告》 | **亲身体验式调研的典范**——32天实地考察，用数据说话 |
| 1927.8 | 八七会议提出"枪杆子里出政权" | 核心认知：武装斗争是中国革命的唯一出路 |
| 1927.9 | 领导秋收起义 | 第一次军事实践 |
| 1927.10 | 率部上井冈山 | 建立第一个农村革命根据地 |
| 1928 | 与朱德会师，朱毛红军成立 | 形成后来领导核心 |
| 1930.1 | 写《星星之火，可以燎原》 | 在悲观情绪中预见革命高潮 |
| 1930.5 | 写《反对本本主义》 | **核心方法论**："没有调查就没有发言权" |
| 1931-1934 | 中华苏维埃共和国主席；遭排斥打击 | 边缘化的三年——成为"闲人"反而系统读书思考 |
| 1934.10 | 开始长征 | 战略撤退的经典案例 |
| 1935.1 | 遵义会议确立领导地位 | 核心转折——在生死存亡关头被重新启用 |

## 成熟期（1935-1945）：理论体系形成

| 时间 | 事件 | 认知意义 |
|------|------|----------|
| 1935.12 | 写《论反对日本帝国主义的策略》 | 统一战线思想系统化 |
| 1936.12 | 写《中国革命战争的战略问题》 | 军事思想体系化 |
| 1937.7-8 | 写《实践论》《矛盾论》 | **哲学体系成熟标志**——把马克思主义哲学中国化 |
| 1938.5 | 写《论持久战》 | **战略预判典范**——在抗战悲观论和速胜论中找出第三条路 |
| 1940 | 写《新民主主义论》 | 中国革命道路的系统理论 |
| 1941-1944 | 延安整风 | 统一思想、确立"实事求是"思想路线 |
| 1942 | 延安文艺座谈会讲话 | 文化路线系统化 |
| 1945 | 中共七大确立毛泽东思想 | 理论体系完成制度化 |

## 认知特征总结

1. **从实践中来**：几乎所有重大理论都建立在具体调研和实战经验基础上
2. **矛盾分析法**：用对立统一框架分析一切问题
3. **逆向思维**：在多数人看好的时候警惕，在多数人悲观的时候发现机会
4. **战略耐心**：能长期等待时机成熟（如长征后的蛰伏）
5. **独立自主**：核心原则——"中国革命斗争的胜利要靠中国同志了解中国情况"
