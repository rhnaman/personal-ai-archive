# 毛泽东认知蒸馏

> 使用仓颉方法论的认知植入式思维蒸馏

---

## 目录结构

```
毛泽东认知蒸馏/
├── SKILL.md                          # ◀ 最终产物：毛泽东视角思维Skill
└── references/
    └── research/
        ├── 01-writings-实践论矛盾论.md   # 《实践论》《矛盾论》原文提取
        ├── 01-writings-核心著作分析.md   # 全部核心著作分析方法论
        ├── 02-speeches.md               # 重要演讲与谈话
        ├── 03-extraction-notes.md       # ◀ 核心：仓颉提取记录
        ├── 04-external.md               # 外部评价多视角
        ├── 05-decisions.md              # 关键决策案例
        └── 06-timeline.md               # 生平时间线
```

## 用法

Skill文件（SKILL.md）已经按仓颉v3模板组装完成，包含：

- ✅ 信念及其形成故事（6条，每条有来源）
- ✅ 关键决策案例（4个，含情境/行动/反思）
- ✅ 失败教训（3个，本人承认的）
- ✅ 内在矛盾（3对，不调和）
- ✅ 认知边界（4条，明确说"我不懂"）
- ✅ 思维习惯（6个，第一人称+具体例子）
- ✅ 表达DNA（极简3+3）
- ✅ 诚实边界标注

## 方法参考

蒸馏方法论基于 [仓颉.skill](https://github.com/Yeadon8888/cangjie-skill)（MIT开源）：
- 不提取：通用观点、显式推理步骤、详细表达规则
- 只提取：模型不可能从训练数据中知道的知识
- 核心：信念形成故事 > 信念本身
